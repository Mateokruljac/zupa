# Predlošci na razini projekta

Ovdje ostaje samo **zajednički shell**:

- `pastoral/base.html`, login
- greške (`errors/`)
- admin overridei

## Domenski predlošci

Svaka Django aplikacija drži svoje predloške u `<app>/templates/<app>/`.

Primjeri:

- `pregled/templates/pregled/dashboard.html`
- `liturgija/templates/liturgija/partials/liturgical_day.html`
- `sakramenti/templates/sakramenti/public/form.html`
- `financije/templates/financije/pages/dugovanja.html`

Ne premještaj domenske stranice natrag u `templates/pastoral/pages/`.
