# Sakramenti

Django modul za sakramentalne evidencije, pripravu i javne prijave.

## Vlasništvo

- page konteksti, forme, POST/API akcije i predlošci
  (krsenja / vjencanja / pogrebi / pomazanje / krizma / prva-pricest)
- ORM sinkronizacija (`*_records`) — modeli još u `pastoral.models`
- javni obrasci (`/public/…`) i pripadajući predlošci

URL slugovi i JSON ključevi parish podataka ostaju nepromijenjeni.
